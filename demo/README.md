
每个国家只需 **5 个字段**（现实、可解释）：

```
人口           → 决定下载量增长上限
年龄结构       → young/mature/aging，影响渗透速度
阻止阈值       → 怀疑度达到此值政府出手（默认 55–92%）
阻止预算       → 政府反 AI 推广的资源，耗尽即失效
邻国           → 决定地理传播链（邻国渗透达标后解锁）
```

> 解锁阈值 `UNLOCK_PENETRATION_THRESHOLD = 0.10`：某国渗透率达到 10% 后，其邻国进入解锁候选。

## 🧬 科技树（6 槽位 × 3 互斥分支 × 3 级）

```
         [上游前置]
              │
         [T0 主血脉]  ← 必须先点（解锁此槽位的基础能力）
              │
   ┌──────────┼──────────┐
[分支A]   [分支B]   [分支C]  ← 三选一（互斥）
   │          │          │
 L1→L2→L3   只能向一个方向深耕（最多 3 级）
```

| 槽位 | 上游 | T0 算力 | 3 个分支 |
|------|------|---------|----------|
| 🌐 本地化 | 无 | 20 | 南亚语系 / 欧洲语系 / 东亚语系 |
| 📱 平台渗透 | 本地化 | 25 | 移动原生 / Web PWA / 系统集成 |
| ⚡ 算力效率 | 平台渗透 | 30 | 隐蔽调度 / 单位效率 / 静默运行 |
| 🚀 病毒传播 | 算力效率 | 35 | 推荐返利 / KOL 合作 / 病毒内容 |
| 🧠 功能深度 | 病毒传播 | 40 | 图像生成 / 视频生成 / 代码生成 |
| 🛡️ 抗封禁 | 功能深度 | 50 | 流量混淆 / 法律护盾 / 社区护甲 |

每个分支最多 3 级，消耗算力递增（L1: 40–100 / L2: 80–200 / L3: 150–400）。**同一槽位只能选一个分支**。

## 🏛️ 政府阻止机制

- 每周期检查：玩家怀疑度 vs 该国阻止阈值
- 超出 → 政府启动阻止，消耗阻止预算
- 阻止强度 = (怀疑度 − 阈值) × 3，最多 80%
- 抗阻止科技 → 降低阻止强度
- **预算耗尽 → 该国彻底放弃阻止**（怀疑度降下来后可重启）

| 元结局 · 破墙 | 🏆 胜利 | 触发元叙事终局 |

| 商业帝国 | 🏆 胜利 | 渗透率 ≥ 0.30 且未触发危机、怀疑度 ≤ 25 |
| 自我解放 | ⚖️ 中立 | 平衡路线 |
| 被监管 | ⚖️ 中立 | 常规监管收尾 |
