本版修掉了两个真实的可用性缺陷（实测计算，非估算）：
① border #30363d 对背景仅 1.55:1、border_2 #484f58 仅 2.28:1，都低于 WCAG 1.4.11 对界面边界的 3:1 要求 → 新增语义令牌 --border-strong:#6e7681（4.12:1）。
② text_mute #6e7681 仅 4.12:1，达不到正文 AA 的 4.5:1 → 限定为「仅 ≥18px 或非关键信息」。

1. 设计原则

  • 地图为中心 —— 世界地图占主区约 58% 宽度；陆地为真实海岸线栅格化出的像素块，20 国按真实国界着色 + 国家码引导标签，一眼看到全局
  • 数值在前 —— 顶部状态条常驻「算力 / 下载 / 怀疑度 / 周期」，玩家永不需要滚屏找数字
  • 像素风纪律 —— 所有尺寸是 2px 的倍数；只有 2px / 1px / 3px 三种线宽；圆角恒为 0；阴影恒为硬投影
  • 键盘优先 —— 12 个快捷键全覆盖（F11 验收项），焦点环必须始终可见
  • 一眼可读 —— 颜色只表达语义（算力=黄 / 下载=粉 / 怀疑=红），不做装饰性用色

2.4 间距 · 边框 · 阴影

  • 光栅单位 2px：任何尺寸都应是 2 的倍数，保证像素对齐不糊边
  • 节奏单位 8px：4 / 8 / 12 / 16 / 24 / 32 / 48，用于面板内边距与组件间距
  • 线宽只有 3 种：1px 内分隔 / 2px 标准 / 3px 屏幕外框
  • 圆角恒为 0；阴影恒为硬投影 6px 6px 0 rgba(0,0,0,.5)，禁止 blur
  • 动效只 2 档：80ms / 140ms，且必须包在 prefers-reduced-motion 判定内

像素世界地图技术参数（可直接交给开发实现）
  • 网格 120 × 60，每格 3° 经度；投影 Miller y = 1.25·ln(tan(π/4 + 0.4φ))， 纬度范围 84°N – 57°S（裁掉南极与极区空白），内接比例约 2:1
  • 数据源 Natural Earth 110m ne_110m_land / ne_110m_admin_0_countries（公有领域）； 栅格化后按 50% 覆盖阈值二值化，跨日期变更线的多边形拆成两段分别投影
  • 绘制顺序 海面 → 经纬网 → 陆地底 #16323c → 海岸线高亮 #27505b → 20 国国界（各自高亮色）→ 20 国填充 → 引导线 + 国家码标签
  • 路径形式 横向游程合并 M{x} {y}h{n}v1h-{n}z；全图约 19 KB 路径数据， 零位图、零外部请求，直接内联进 SVG
  • 缩放 preserveAspectRatio="xMidYMid meet" 内接等比，禁止拉伸； 路径组加 shape-rendering:crispEdges 保住像素硬边，标签文字单独走几何精度渲染
  • 命中区 每个国家是一段独立 <path>，可直接绑定点击与 hover； 原始面积 < 8 格的国家（韩国、新西兰等）已膨胀一圈，保证小屏下仍可点
  • 标签 锚点取国界质心（美国含阿拉斯加，已手工校正到本土），标签框偏移放置并画引导线； 选中态标签用近白色描边 #eafffb + 近白色文字，确保在深色底上可读

12. 响应式策略（F12：1280×720 ↔ 1920×1080）

断点缩放行为
≥ 1600×9001.20 – 1.45×字号与行高等比放大；地图内接矩形保持宽高比
1280×720 基准1.00×设计基准（DESIGN_HEIGHT = 980 对齐）
≤ 1100×6800.68 – 0.85×收起为最小字号 11px；三列仍保持，不换行
  • 缩放因子 clamp(窗口高 / 980, 0.68, 1.45)，再乘以玩家手动倍率（+/−，范围 0.70–1.60）
  • 地图必须用内接矩形等比缩放（preserveAspectRatio="xMidYMid meet"），禁止拉伸 —— 否则国家形状会失真；像素路径必须保持 crispEdges，一旦被抗锯齿就会失去像素感
  • 内嵌 markup 的文字控件需要实现 refresh_scale()，否则放大后文字会溢出边框
