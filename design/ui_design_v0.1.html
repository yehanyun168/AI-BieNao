AI 别闹 · 像素风 UI 设计稿 v0.1

目标：模仿 Plague Inc. 的大地图 + 紧凑操作面板布局；采用 8/16-bit 像素风；先审稿再改代码。

1. 设计原则

  • 地图为中心 —— 世界地图占满主区，国家以发光点 + 像素色块呈现（解决"看不见地图"问题）
  • 极简操作 —— 顶部状态条 + 底部 3 个技能按钮 + 侧边可折叠面板
  • 像素风 —— 2px 硬边框、无渐变、限制色板、像素字体（系统等宽）
  • 即视即玩 —— 不需要教程，新玩家看一眼就知道"点地图→点技能→点科技"

8. 关于"看不见地图"的问题诊断

症状：用户报告主游戏界面中看不到世界地图

可能的根因（按可能性排序）：
  1. FlagWidget 嵌套后尺寸计算异常，国家像素块覆盖了地图背景
  2. PixelMap 整体高度被压缩为 0（与左侧列表的 size_hint 冲突）
  3. 标签 Label 的 pos_hint 设置错误，把国家像素推到了地图外
  4. Kivy DPI 144 下，字体被裁切让某些组件看不见
在像素风新 UI 里如何彻底解决：
  • 地图作为独立的 BoxLayout 子项，使用 size_hint=(1, 1) + 固定最小高度 min_height=540px
  • 国家像素用 canvas.before 直接画到地图背景上，而不是 FloatLayout 子组件
  • 所有 UI 元素用 image-rendering: pixelated + 2px 实边框，避免抗锯齿让元素变模糊
