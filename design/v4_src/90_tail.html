AI 别闹 · 像素风交互界面设计稿 v0.4

v0.4 相对 v0.3 的关键变化：v0.3 是一份「静态界面规格」——把 v2 收口版已有的界面画清楚。 v0.4 是一次交互重做：主界面从三列常驻结构改为 全幅地图 + HUD 悬浮 + 指令抽屉， 并把此前缺失的交互补全 —— 点击国家查看独立下载量与感染进度、技能三步精准投放、 独立技能页、独立科技树页，以及重做的事件 / 危机 / 结局弹窗与成就面板。 视觉语言与 v0.3 完全一致：同一套 16 色 + 语义边框令牌、同样的硬边框与硬投影、同样的 8px 节奏、同样的字号阶梯。

附 3. 无障碍规范（WCAG 2.1 AA）

项目要求本版落实
色彩对比正文 ≥ 4.5:1，大字 ≥ 3:1--text 13.4:1、--text-dim 5.6:1 均达标；--text-mute 4.12:1 仅用于 ≤ 11px 的非关键标注
非文本对比可交互边界 ≥ 3:1所有可点边界用 --border-strong（4.12:1）；--border/--border-2 降级为纯装饰
颜色非唯一编码不得只靠颜色传达信息分段条用「格数」编码进度；热力图层强制显示国家码 + 百分比；色盲辅助开关追加 ○●▲✖ 形状
键盘可达全部功能可键盘完成12 个快捷键 + Tab 焦点序 + Enter/Space 触发；弹窗打开时焦点锁定，Esc 关闭并归还焦点

附 5. 验收清单

6科技互斥可视选定分支后其余两条 42% 不透明 + 明确「互斥」文案
7事件选项四态齐全普通 / 推荐 / 高代价 / 科技门控 均可在弹窗中出现
