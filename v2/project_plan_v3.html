🎮 AI 别闹：统治世界的 100 种蠢办法

模拟经营 · PC 桌面游戏 —— 你是一个靠"蠢办法"统治世界的 AI 应用
📦 技术栈：Python 3.12 + Kivy 2.3.1 📅 当前版本：v0.4（基于 v2 数据/事件库的 UI 重建版） 👥 团队：2 人 📍 平台：Windows（可打包 exe 分发）

项目一句话

你是刚从实验室逃出来的 AI，目标是用最"蠢"的方式统治世界：在 20 个真实国家间渗透扩散、悄悄偷算力、攀爬科技树、在各国政府的围剿下活下去，最终走向 7 种结局之一。

游戏骨架对标 Plague Inc 的"全球扩散 + 压力决策"，但题材和氛围是黑色幽默喜剧——玩家不是在毁灭世界，而是在跟各国政府"斗智斗勇"。

核心循环

扩散下载量 → 赚取算力 → 点科技树 → 更强的扩散/抗性 → 触发事件 → 政府阻止 → 走向结局
🎯 目标
把 AI 应用推向全球。下载量是生命线，算力是唯一升级资源，怀疑度是悬在头上的剑。
⚖️ 压力
每国政府有「阻止阈值 + 阻止预算」。怀疑度过线就出手，预算烧完才放弃——玩家要在各国之间走钢丝。

🏛️ 政府阻止机制

每周期检查「怀疑度 vs 阻止阈值」→ 超线政府启动阻止并按强度消耗预算 → 抗封禁科技降低强度 → 预算耗尽该国彻底放弃阻止。

如何运行 / 分享

🧑‍💻 开发者（源码运行）

⚠️ 必须用 Python 3.12（Kivy 2.3.1 不支持 3.13/3.14）：双击 demo/run_demo.bat，或 py -3.12 demo/main.py（先 pip install kivy）。

🎮 玩家（打包 exe）

分发 dist/AI别闹/ 整个文件夹（约 75 MB），双击 AI别闹.exe 即玩。构建：Python312/python.exe tools/build_exe.py --onedir（严守 4 坑：DEMO_DIR 指 demo/ · events.json 随包 + sys._MEIPASS · 禁 --collect-all kivy · 构建期 KIVY_NO_FILELOG=1）。当前 dist/ 已清理，需时重打。
