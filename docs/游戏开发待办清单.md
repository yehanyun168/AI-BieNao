## 🔴 P0 — 阻塞发布

### P0-1 新手引导 / 教程系统 ✅ 已完成（2026-09-10 续做）
- **本轮修复**：① 引导文字越界（气泡坐标混用窗口系/overlay 局部系 → 改用 `overlay.to_local` + 稳健夹紧/翻转 + ScrollView 正文）；② 补全 `_build_bubble` 缺失的 `BoxLayout`/`ScrollView` import（首跑必崩，单测未覆盖，靠截图脚本发现）
- **做什么**：给完全没玩过的用户一条上手路径，消除"首局懵"
- **怎么做**：
  - 新增 `demo/tutorial.py`（轻量步骤机 `StepMachine`），引导模式检测 `engine.round == 0` 或 `not player.seen_tutorial`
  - 引导步骤：① 世界地图+你在推流 ② 选国家投放（高亮 S04 `DropPreview`）③ 技能 1–6 含义（S05 `SkillPage` 浮层讲解）④ 读面板 S03 `InspectorPanel` 渗透率/怀疑度 ⑤ 危机怎么选 S08 ⑥ 周期倒计时 `CountdownBar` 怎么看
  - UI 复用已有 `make_modal` + 高亮遮罩（dim 其他、亮一个控件）；**别用 `PageScreen.close_cb`（从未实现）**
  - 状态持久化：`player.seen_tutorial` 写入存档（`main.read_slot_rows` / `newest_save_path`）；S12 设置页加"重看教程"按钮
  - Esc / Space 可跳过，跳过后标记 seen
- **最终效果**：新用户 3 分钟内理解核心循环，首局不再懵；给朋友玩的留存测试能跑通

### P0-2 首局节奏曲线重排
- **做什么**：解决 30s/周期 下"前 10 分钟无事可做"（周期 4 就解锁 4 国，减速把空窗放大）
- **怎么做**：
  - `engine.py` 把"已解锁国家数"与 `UNLOCK_PENETRATION_THRESHOLD` 解耦——引导期（round 1–6）强制只开放 2–3 个低难度国（如 CN/KR/IN），round 7+ 才按阈值放开
  - `v2/events.json` 加 6 条"新手引导事件"（纯叙事+提示，非战斗），`engine.tick_one_round` 引导期优先触发
  - 新档默认 `speed_idx=0`（×0.5，45.9min/局）给足反应时间；老档保持
  - 验证：`python demo/balance_sim.py --seeds 30` 确认曲线改动不破坏平衡 + 手测首 10 分钟
- **最终效果**：减速到 30s 后前 10 分钟有连续事可做（教学事件+渐进解锁），无空窗；首局平滑

### P0-3 中后期内容重复
- **做什么**：解决"后期国家推完、只剩等结局"的重复感
- **怎么做**：
  - `engine.py` 加"动态委托"系统：每 N 周期生成随机委托（如"10 周期内让 RU 渗透率破 30%"），完成给算力/成就进度，失败给怀疑度惩罚
  - 加"反制机制"：被监管国周期性格查反击，逼玩家换策略/换目标
  - 调 7 结局判定阈值（`engine.py`），让 empire/liberation 等偏难结局更可达
  - 验证：`balance_sim --seeds 30` 看结局分布更均匀（目标每结局 ≥5%）
- **最终效果**：一局后段仍有目标驱动与变数，重开不觉得"同一套流程"

### P0-4 音效 / 音乐 🟡 部分完成（音效已接，BGM 未做）
- **做什么**：从 0% 补基础音频（点击/投放/危机/结局）
- **怎么做（已落地，实现与原计划不同）**：
  - 库：未引入 pygame，直接用 Kivy 自带 `kivy.core.audio.SoundLoader`（更轻、零额外依赖、Py3.12 兼容）
  - 资源：`tools/gen_sfx.py` **程序合成 8 个 CC0 WAV**（click/select/cast/success/fail/crisis/end_win/end_lose）到 `demo/assets/sfx/`；纯正弦/方波+包络，无版权/无联网
  - 管理器：`demo/sfx.py` 失败安全——任何加载/播放异常静默 no-op，不依赖音频后端；打包走 `sys._MEIPASS`
  - 接线：`on_map_country_click`(select) / `_confirm_drop`(cast) / `open_page`(click) / `show_crisis_popup`(crisis) / `show_ending_popup`(win/lose)；S12 新增「音效」开关 → `sfx.set_enabled`
  - **BGM 未做**（循环背景乐缺素材，留待后续）
- **最终效果**：UI 操作 + 关键事件有音效反馈，可一键静音；游戏"活"起来

## 🟡 P1 — EA 前

### P1-1 数值均衡（被监管 43.3% 偏斜）
- **做什么**：让监管/非监管路径胜率更均衡
- **怎么做**：跑 `balance_sim --seeds 30` 看结局占比与平均回合 → 调 `engine.py` `SUSPICION_CRISIS`/怀疑度衰减/监管国权重/`UNLOCK_PENETRATION_THRESHOLD` → 迭代到 7 结局均 ≥5% 且平均回合 30–50
- **最终效果**：无明显"唯一最优解"路径，策略有取舍

### P1-2 build 多样性
- **做什么**：自动玩家总选南亚分支 → 让其他路线也可行
- **怎么做**：在 `balance_sim.py` 自动策略加多样性权重；`engine.py` 调技能在不同国家组合的 ROI；加"技能协同"（如 stealth+bypass 在特定洲加成）
- **最终效果**：多套可行 build，meta 不单一

### P1-3 国家 vibe 差异化
- **做什么**：20 国玩法同质，缺"性格"
- **怎么做**：`data.py` 的 `Country` 加 `vibe`/`preferred_skill`/`resistance` 字段；`world_map`/`InspectorPanel` 展示；`engine` 用这些字段调各国渗透率/怀疑度增速
- **最终效果**：选国有策略意义，"先打软的"成玩法

### P1-4 事件效果预览
- **做什么**：投放/选技能前能看到"会怎样"
- **怎么做**：`engine` 暴露纯函数 `preview_skill(sid, targets)`；在 S04 `DropPreview` / S05 `SkillPage` 用 `_effect_chips()` 风格小条显示预计渗透率Δ/怀疑度Δ
- **最终效果**：决策有信息支撑，降低 trial-and-error

### P1-5 重玩性（难度/种子）
- **做什么**：同局不同体验
- **怎么做**：`engine` 加 `seed` 参数驱动事件/委托随机；main 新档随机种子、S12 可输入种子；加 2–3 档难度（影响怀疑度增速/初始算力）
- **最终效果**：速通/挑战有目标，重开不腻

### P1-6 《20 国详细介绍》+ 演示视频
- **做什么**：对外素材
- **怎么做**：基于 `data.py` 各国字段写 `v2/country_guide.md`（含单国像素旗，用 `make_screenshots` 抽）；演示视频 OBS/Edge headless 录 ×1 速通剪 60–90s
- **最终效果**：朋友/社区有资料可看，降上手门槛

### P1-7 on_motion / on_a11y 实际生效 ✅ 已完成（2026-09-10）
- **怎么做（已落地）**：
  - `REDUCE_MOTION`：`_set_motion_idx` 触发 `_reschedule_countdown()`，倒计时刷新间隔 0.25s→1.0s（减少每帧重绘 = 缓解卡顿）；全局在 `CountdownBar` 更新处读取
  - `A11Y_SHAPES`：`LegendChip` 加 `shape_lbl` 形状符号；`LegendBar.apply_a11y()` 在四态图例追加 ○●▲✖ 形状（on=●/sel=▲/blk=✖/lk=○）+ 文字前缀；切换时实时重绘（图层模式不生效）
- **最终效果**：两项设置真正可用，色弱/动效敏感用户可正常游玩
