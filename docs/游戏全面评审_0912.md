## 0. 评审团总评（一句话各角色）

- **游戏策划**：核心循环「渗透 ⇄ 怀疑」双压力成立且被 1800 局数据证明有效，但**单局决策深度只有成熟竞品的 1/4~1/3**，玩 5-10 局后内容新鲜感见底。
- **系统设计**：系统骨架（委托/反制/成就/存档/难度/种子/i18n）**完整度超出同体量独立游戏平均线**；短板在系统的"个体差异化"——20 国同质、6 技能共用一套数值骨架。
- **数值平衡**：工具链成熟度（模拟器+矩阵基线+逐位回归+巡检阈值 v2）**超过绝大多数独立项目**；但两个已确认的平衡洞（单 tick 怀疑 +45~97 尖峰、合规之王 1% 不可达）还没修。
- **美术表现**：像素风格化路线正确、令牌体系统一（86 处 hex 仅 5 类绕过）；**缺 BGM、缺角色/叙事表现力、地图无地形与热力层**。
- **程序架构**：分层依赖 + pre-commit + 四件套验证 + 工具豁免登记——工程纪律是我见过的独立项目前 5%；技术债集中在 7 个超 800 行文件与每 tick 重建 UI。
- **运营**：试玩报告模板 v2 + agent 巡检管线是**很好的运营雏形**；但零真人回收（M1 最大风险未解除）、无成就墙、无局外收集展示、无发布渠道规划。

**综合判定：GO——产品地基质量高于平均，当前不是"要不要继续"的问题，而是"内容量与首局体验能不能撑起 EA"。**

## 2. 与成熟同类游戏系统对比

**对标对象选型**：本作机制与 *Plague Inc.*（全球渗透 + 检测压力 + 世界地图）高度同构，是其"AI 伦理反转版"；辅助对标 *Rebel Inc.*（同厂、政府压力双轨）、*Universal Paperclips*（AI 主题、信任度机制互为镜像）、*Reigns*（极简多结局抉择）。

| 系统 | 《AI 别闹》现状 | Plague Inc. / Rebel Inc. | 差距判定 |
|---|---|---|---|
| 核心压力循环 | 渗透率 ⇄ 怀疑度，危机三选一 | 严重度/可见性/致死性三角 + 解药进度 | **同构且成立**，但对手是"三角"，本作是"两轴"——策略空间天然少一维 |
| 科技/升级树 | 6 槽 × 3 分支 × 3 级（约 24 个实际决策点） | 症状/传播/能力三树 100+ 项 + 进化连锁 | **深度差 4 倍**；本作分支间无协同/反协同，build 无个性 |
| 开局差异化 | 无（每局同起点，仅种子不同） | Plague 基因改造 10+ 槽、Rebel 顾问系统 | **缺失**——重玩动机的最大缺口 |
| 病原体/模式差异 | 1 种玩法模式 | Plague 11 种特殊瘟疫（规则级差异） | **缺失**，但属 1.0 后内容 |
| 国家/地区个性 | 20 国仅数值不同（无 vibe 字段） | Rebel 地区有气质/民生/叛军差异 | **明确待办（P1-3）未做**，"先打软的"策略不存在 |
| 事件/新闻系统 | 37 条 v2 事件 + 6 危机 | Plague 新闻流持续营造世界感 | 数量级尚可，**缺串联叙事**（事件间无因果链） |
| 政府反应 | 反制（查/关/缴）+ 收网 92+0.5 | Plague 解药研发随严重度加速 | 机制成立；**玩家对反制的预判手段弱**（无研发进度条类信息） |
| 结局/成就 | 7 结局全条件声明式 + 15 成就 | 同类普遍 10+ 结局 + 局外图鉴 | 结局数量达标；**成就无展示墙、无局外收集反馈** |
| 多结局可达性 | 元 4.5% / 合规 1%（AUTO 口径） | Plague 特殊成就普遍 <1% | 稀有结局本身不是问题，**问题是"知道有但够不着"没有任何引导** |
| 教学/引导 | 12 步引导 + 重看入口 ✅ | Plague 无内建引导（靠难度分级） | **本作更好** |
| 难度/速度 | 3 难度 × 4 速度 ✅ | 同级 | 持平 |
| 本地化 | 中英双语全量 ✅ | 多语言 | 独立项目中**领先** |
| 音频 | 8 合成音效，无 BGM | 全都有 BGM+氛围 | **明显差距**（EA 门店页会直接暴露） |
| UGC/自定义 | 种子可复现（agent 已用） | Plague 自定义场景工坊 | 种子分享是现成的轻 UGC 雏形，**未包装** |

## 3. 八维度评估

> 评级：★★★★★=成熟竞品水准；★★=原型级。括号内是对比对象下本作的相对位置。

### 3.1 核心玩法机制 ★★★☆☆
- **成立的部分**：渗透-怀疑双压力被 1800 局验证——主动冒险（default）五五开、稳健合规（compliance）六成半、彻底躺平（afk）全灭，压力模型分层清晰，这是很多原型做不到的。
- **不足**：① 决策密度不均——前 20 周期几乎无关键决策（首危机 43.2 周期，计划书 PR-10 已认定"压力倒挂"），后期在 45+ 周期决策风暴后突然等结局；② 两轴压力缺第三维：Plague 有"致死性"这种**玩家可主动选择的第三极**，本作缺一个"收益换风险"的主动阀门（如主动挑衅类高风险行动）；③ 危机三选一已接近 Reigns 的手感，但选项间长期收益差异未被玩家感知（选完没有后续回响）。

### 3.2 系统完整度 ★★★★☆
- 委托/反制/成就/存档（含迁移）/难度/种子/i18n/引导全链路齐备，**系统骨架完整度高于同类 EA 独立游戏平均线**。
- 不足：① 技能只有 6 个且共用一套冷却-怀疑骨架，中后期无新技能解锁感；② 委托 6 模板循环使用，15 局后可背板；③ 成就只进不出的"暗箱"——打出成就无展示位（S03 成就墙在 ardot backlog 未做）。

### 3.3 数值平衡 ★★★☆☆（工具链 ★★★★★）
- 工具链是本项目**最亮眼的资产**：模拟器 → 1800 局矩阵基线 → 逐位回归 → 阈值 v2 实测校准 → doom 回测。任何数值改动 20 秒内可全量验证，这套东西值得保持到 1.0 以后。
- 三个已确认待修洞：① **单 tick 怀疑 +45~97 尖峰**（31 次/119,918 tick）——玩家视角就是"怀疑莫名爆表"，M0 数据已定位中后期（tick 21-45）为高发段；② 合规之王 AUTO 口径 1%（真人可能更低），叙事与判定语义漂移（计划书 PR-14）；③ 组间方差（P1-2）未做——同一策略 90 局分布的稳定性未验证。

### 3.4 关卡与内容量 ★★☆☆☆
- 20 国 / 37 事件 / 6 委托的量能支撑 **约 5-10 局（1.5-4 小时）的新鲜感**——给朋友试玩够用，**撑不起 EA 的期望游玩时长（独立 EA 中位数 5-10 小时）**。
- 对比：Plague Inc. 用 100+ 升级 × 11 模式 × 基因 build 把同样的循环做出 50+ 小时。本作需要内容量翻倍以上，且优先扩"横向差异"（技能/国家性格/事件链）而非"纵向数值"。

### 3.5 美术与音效表现 ★★★☆☆
- 优点：像素风统一、360×180 地图 + 像素旗 + 令牌色板（check_map_palette 4/4）、遮罩弹窗风格一致。
- 缺口（按玩家感知排序）：① **无 BGM**——一局 20 分钟静默，EA 商店页 30 秒视频里会被直接感知；② 地图无地形/城市灯/渗透热力可视化（ardot S06 已设计未做）——渗透进度目前只有数字与色块；③ 无角色/叙事画面（结局只有文字），7 个结局的戏剧张力浪费了；④ 1.5× DPI 半像素糊（P2-2）。

### 3.6 用户体验与界面交互 ★★★★☆
- 14 屏全部有截图回归、引导有跳过与重看、无障碍（形状图例/减少动效）做了、双语全量——**这是本作相对独立平均线最强的一维**。
- 待修：① preview_skill 缺失（投放前看不到"会怎样"，PR-12，计划书 P1-2 性价比最高）；② 压力倒挂（3.1 已述）；③ 顶栏火花图语义归一化已修但值得真人复验。

### 3.7 性能优化 ★★☆☆☆（未验证 ≠ 不可用）
- 引擎层极快（1800 局 20 秒），但**渲染层没有数据**：无 fps 探针（PR-16）、每 tick 重建 120 控件（ui_v4_screens:2221）、5466 个 Canvas Rectangle 常驻。核显目标是明确的，却没有任何一帧实测数据。
- 判定：不一定是问题，但**"不知道有没有问题"本身就是 P1 级风险**——计划书 P1-3（帧率探针 3 人时）应在下一轮立即做。

### 3.8 长线运营设计 ★★☆☆☆
- 已有雏形：试玩报告模板 v2 + agent 巡检管线（可周期性跑矩阵对比基线漂移）+ crash.log 回传约定——这套"人工+自动"混合测试运营在独立项目里罕见。
- 缺失：① 局外目标（成就墙/结局图鉴/统计面板）——二周目动机的载体；② 无更新内容管线预告（EA 更新日志/路线图页面素材）；③ crash 上报是手动回传，回收率取决于玩家责任心；④ 无平台与定价规划（Steam/WeGame/移动端的像素策略品类均价、评测权重完全未研究）。

## 6. 分阶段改进路线图

```
阶段 0「数据回来」（本周）            ← 一切的前提
  A1 发包 → 回收 ≥3 份真人报告（模板 v2 已就绪）
  顺带：A4 前置分析（尖峰来源定位，纯读数据不动数值）
  出口：≥3 份有效反馈 + 尖峰根因结论

阶段 1「体验补强」（1-2 周）
  A2 首局压力改造 → A3 尖峰修复 → A4 合规语义+方差
  B2 preview_skill → B4 帧率探针
  每步过 L1/L2 回归 + M0 矩阵对比基线
  出口：二次试玩无"看不懂/莫名爆表/点了没反应"；fps 有数

阶段 2「EA 就绪」（第 3-5 周）
  B1 BGM → B3 热力地图 → B5 技能扩容 → B6 成就墙/图鉴
  内容量目标：技能 10、事件 45+、成就墙上线
  出口：商店素材（含 BGM 的 60-90s 视频）可拍；试玩 2 小时不重样
```
