# 《AI 别闹》试玩报告模板（v1 · M1 真人测试用）

> 感谢参与试玩！整份报告 **10-15 分钟**能填完。格式不限，直接在每条下面写即可。
>
> **优先级标注**：🔴 P0 必填（缺了报告无效）｜🟡 P1 尽量填｜🟢 P2 想到就写。
> **如果你只有 5 分钟：只填所有 🔴 项。**
>
> **评分标准（全文统一 1-5 分）**：1=很糟 2=偏差 3=及格/一般 4=不错 5=很好。
> 特殊量表会在条目里单独注明。
>
> **描述深度总则**：主观题写 1-3 句即可，不要写论文；**照实写**，
> "一头雾水 / 太无聊 / 看不懂"这类反馈比客气话有用一百倍。

---

## 0. 基本信息（🔴 全部必填）

| 条目 | 填写说明 | 你的填写 |
|---|---|---|
| 昵称/称呼 | 随意，方便我们跟进追问 | |
| 测试日期 | 如 2026-09-13 | |
| 实际游玩时长 | 大约即可，如 40 分钟 | |
| 打了几局 | 从开新档到打出结局（或放弃）算一局 | |
| 游戏包版本 | 解压后 `AI别闹` 文件夹里 `VERSION.txt` 的 commit 值（如 5e6d700） | |
| 电脑环境 | Windows 版本 + 显卡类型（核显/独显，独显写型号）+ 分辨率。例：Win11 / 核显 Radeon 610M / 2560×1470 | |
| 是否闪退过 | 是/否。若是 → `AI别闹` 文件夹下的 `crash.log` **必须随报告回传** | |

## 1. 整体体验与第一印象

- **1.1 🔴 第一印象**：用 **3 个词**形容打开游戏后的感受。
- **1.2 🔴 整体评分（1-5）**：__
- **1.3 🔴 开局 5 分钟**：你明白自己要做什么了吗？（完全明白 / 大概明白 / 一头雾水）
  再用一句话写下**你以为**的游戏目标——写错了才是最有价值的信息。
- **1.4 🟡 推荐指数（0-10）**：有多想推荐朋友来玩？
- **1.5 🟡 最惊喜的一个点**（1-3 句）
- **1.6 🟡 最失望的一个点**（1-3 句）

---

## 2. 核心玩法与操作手感

- **2.1 🔴 三大资源理解**：算力 / 下载量 / 怀疑度，各自是干什么的？
  逐个用一句话说明。说不清就写"不清楚"——这是重要信号，不要查攻略再填。
- **2.2 🔴 操作手感分项评分（各 1-5）**：
  - 鼠标点击 / 选中响应速度：__
  - 世界地图选国家（能否顺利点到想点的小国家）：__
  - 科技页（解锁 / 升级）：__
  - 技能页（购买 / 使用）：__
  - 委托系统（接单 / 看进度 / 结算）：__
- **2.3 🟡 顶栏青色的"下周期预测 +Δ"数字**：注意到了吗？看懂了吗？对决策有用吗？
- **2.4 🟡 找不着北的界面**：哪个界面让你不知道该干嘛（如果没有写"无"）。
- **2.5 🟢 最"上头"的环节 & 最想跳过的环节**。

---

## 3. 画面与音效

- **3.1 🟡 像素画面整体观感（1-5）**：__
- **3.2 🟡 世界地图可读性**：20 个国家能否分清？颜色 / 信标 / 标签框够不够用？（1-5 + 一句话）
- **3.3 🟡 文字可读性**：字号与中文显示是否舒服？（1-5）
- **3.4 🔴 流畅度（1-5）**：__ + 主观描述（流畅 / 偶尔卡 / 经常卡）+ **什么场景最卡**
  （开局 / 中期 / 打开大地图 / 结算时…）。
  ⚠️ 若你的电脑是核显（轻薄本常见），请务必确认第 0 节写了显卡信息，这直接决定我们的优化方向。
- **3.5 🟡 音效**：点击 / 选中 / 施法 / 危机 / 成功 / 失败 / 结局胜负等音效，
  哪些听到了？有没有太吵 / 太怪 / 出现时机不对的？
- **3.6 🟢 目前没有背景音乐**：对你体验影响多大？（1=毫无影响 5=很难受）

## 4. 问题与 Bug（🔴 必填——真的没有也请写"无"）

**填写要求：**
- **现象描述**：一句话说清"你看到了什么"（别只写"卡了/崩了"，写清哪里、什么样的卡/崩）。
- **复现步骤**：从"打开游戏"开始编号 1. 2. 3. 写下来；不能稳定复现的标"偶发"，
  并补一句"当时正在做什么"。
- **证据**：能截图 / 录屏的一定附上；闪退必附 `AI别闹` 文件夹下的 `crash.log`。

| # | 现象（一句话） | 频率（必现/偶发 n 次） | 复现步骤（1.2.3.…） | 证据（截图/录屏/crash.log） |

| 例 | *点科技页"解锁"按钮后界面卡住 2 秒* | *偶发 2 次* | *1. 打开游戏 2. 打到第 20 周期 3. 开科技页 4. 点解锁* | *录屏.mp4* |
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |
| … | （行数不够可自行添加） | | | |

## 5. 难度曲线与节奏

- **5.1 🔴 难度感受（1-5，1=太简单 3=刚好 5=太难）**：__
- **5.2 🔴 最难的阶段**：开局前 10 周期 / 中期 / 后期冲结局 / 说不上来。
- **5.3 🔴 输掉的时候**：你知道自己为什么输吗？（完全知道 / 大概知道 / 完全懵）+ 一句话说明。
- **5.4 🔴 一局时长感受**：太长 / 合适 / 太短；打出结局了吗？是哪个结局？
- **5.5 🟡 开局前 10 周期的节奏**：无聊 / 刚好 / 太赶？想不想跳过前面这段？
- **5.6 🟡 多结局**：你知道游戏有多个结局吗？打出结局后想开二周目探别的结局吗？

## 6. 改进建议

- **6.1 🔴 如果只能改一件事**：你最想改什么？**只写一条**（逼自己排序，第一条最有价值）。
- **6.2 🟡 其他建议**：自由发挥，1-5 条，每条一句话。
- **6.3 🟢 愿意继续参加后续版本的测试吗？愿意的话留个联系方式？**
