## 阶段 0 —— 数据前提（本周，不做完不进入下一阶段）

### T01 🔴 P0 · 真人测试闭环
- **说明**：按 `docs/试玩报告模板.md` v2 发包，回收 ≥3 份有效反馈。当前回收 0/3，是**唯一未解除的 M1 风险**——所有产品判断都悬在此项上。
- **降级方案**：7 天回收 <2 份 → 作者录屏自评 + 扩招至 5 人。
- **建议顺序**：**1（第一件事，今天就发）**
- **难度**：低（行政成本）｜**产出**：≥3 份填好的报告 + crash.log（如闪退）

### T02 🔴 P0 · 怀疑尖峰根因定位（纯分析，不动数值）
- **说明**：M0 巡检已抓到 31 次「单 tick 怀疑 +45~97」（占 0.026%，集中在 tick 21-45 中后期）。用 `tools/data/playtest_baseline.json` 的 delta 直方图 + 逐局时间线定位叠加来源（疑似事件 +12、委托失败 +5、反制 +3、偷算力项在同一 tick 撞车）。
- **建议顺序**：2（可与 T01 并行，纯读数据）
- **难度**：低-中（2-3 人时）｜**产出**：根因结论 + 修复方案草案
- **注意**：只定位不修，等 T01 反馈回来确认玩家真实感知再动数值。

## 阶段 1 —— 体验补强（1-2 周，T01 反馈回来后启动）

### T03 🔴 P0 · 首局压力改造
- **说明**：首危机均值 43.2 周期、12/30 局 60 周期内无危机——前 20 分钟无关键决策，是留存最大杀手。三项独立开关式改动：① 解锁门控（单周期最多 2 国，溢出排队）；② 引导期 tick 1-6 关闭随机事件、改固定教学事件；③ 新档默认速度降一档。
- **验收**：首危机均值 ≤30；60 周期无危机局 ≤3/30。
- **建议顺序**：3｜**依赖**：T01 反馈
- **难度**：中（6 人时）｜**风险**：影响结局分布，每步必跑矩阵并贴结果

### T04 🔴 P0 · 怀疑尖峰修复
- **说明**：按 T02 结论实施——选项：同 tick 叠加设聚合上限 / 关键来源错峰 / 高算力期偷算力项加软上限。同步推进**怀疑度重标定专项**。
- **验收**：矩阵巡检 `sus_delta_hard` 计数归零；阈值 v2 的 REVIEW 线（45）长期占用率下降。
- **建议顺序**：4｜**依赖**：T02
- **难度**：中（2-4 人时）｜**证据**：修复前后矩阵 JSON 对比

### T05 🔴 P0 · 合规之王语义修正 + 组间方差回归
- **说明**：合规之王 AUTO 口径 1%（目标 ≥5%），且名「合规」却以「抗封禁 T0」为条件（语义漂移），真合规科技 `legal_shield` 前置 >55 周期结构不可达。二选一：改判定条件前置 / 只加 AUTO 策略验证不碰阈值。附带做完 P1-2 组间方差回归（90 局分布稳定性）。
- **验收**：7 结局全 ≥5%；组间方差达标。
- **建议顺序**：5｜**依赖**：T04（数值先稳定）
- **难度**：中（4 人时）｜**注意**：合规上升会造成元结局零和下降，需拍板接受稀有结局还是继续调

### T06 🟡 P1 · 技能效果预览补齐
- **说明**：`engine.preview_skill()` 已存在，需确认 S04 投放预览 / S05 技能页是否全量接线（投放前显示预计渗透 Δ / 怀疑 Δ）。若已接线则仅需真人复验。
- **建议顺序**：6｜**难度**：低-中（1-2 人时，视接线状态）
- **风险**：预览公式必须与结算同源，否则反噬信任

### T07 🟡 P1 · 帧率探针落地 + 核显基线
- **说明**：`demo/perf.py` 已存在（含 p50/p95/长帧统计）。需在高压场景（20 国全开 + 抽屉 + 动效全开 + ×4 速 200 周期）实跑一次核显机型，产出基线并存档。
- **建议顺序**：7｜**难度**：低（1 人时跑测 + 记录）
- **产出**：`perf.log` 基线（空闲 ≥55fps / tick 帧 ≥30fps / p95 ≤33ms 三条建议阈值实测校准）

### T08 🟡 P1 · 二次试玩验证
- **说明**：T03-T06 改完后，回访 T01 的 3 位试玩者跑第二局，确认「看不懂 / 前段空 / 莫名爆表 / 点了没反应」四类问题清零。
- **建议顺序**：8｜**依赖**：T03-T07
- **难度**：低（行政）｜**出口**：阶段 1 结束

## 阶段 3 —— 1.0 体量（第 6-10 周）

### T14 🟢 P2 · 国家 vibe 差异化
- **说明**：20 国目前仅数值不同。`data.Country` 加 `vibe` / `preferred_skill` / `resistance` 字段，UI 展示，引擎用这些字段调渗透与怀疑增速——让「先打软的」成为策略。
- **建议顺序**：14｜**难度**：中｜**依赖**：T11（技能池先扩容）

### T15 🟢 P2 · 事件叙事链
- **说明**：37 条 v2 事件目前是独立随机数，无世界感。挑 8-10 条改造成 3 段式链（伏笔 → 升级 → 收束），接世界状态触发。
- **建议顺序**：15｜**难度**：高（文案产能 + 引擎钩子）
- **验收**：链式事件在单局内至少完整触发 1 条

### T16 🟢 P2 · 特殊模式（EA 更新素材）
- **说明**：模式单一导致重玩深度上限低。做一个规则级差异模式，如「白名单模式」——只许在许可国运营，怀疑双倍但合规加成。
- **建议顺序**：16｜**难度**：高（数值重构 + 全矩阵验证）

### T17 🟢 P2 · 平台与发布规划
- **说明**：商店页素材（含 T09 BGM 的 60-90s 视频）、定价研究（像素策略品类均价）、评测名单、更新路线图页。
- **建议顺序**：17｜**依赖**：T09 + T10（素材齐）｜**难度**：中
