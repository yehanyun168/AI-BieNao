## 〇、审查依据（先确认了 4 条技术事实，结论都建立在它们之上）

| 核查项 | 实测结果 | 影响 |
|--------|----------|------|
| Kivy 能否播 OGG/MP3 | **能**。项目环境实测：WAV/OGG/MP3 三者 `SoundLoader.load()` 全部成功（mp3 时长正确读到 82.34s） | 音频素材**不必转格式**即可用 |
| 项目音频加载实现 | `sfx.py` / `bgm.py` 都**硬编码 `.wav` 后缀**（`name + '.wav'`） | 用 OGG/MP3 素材需改 3 行代码（或转 WAV） |
| 项目像素纪律 | 16 色硬调色板（`pixel_ui.COLORS`，GitHub Dark 系：底 #0d1117 / 青 #4ec9b0）；**圆角恒 0、线宽 1/2/3px、光栅 2px、硬投影 6px6px0** | 暖色/彩色素材必须重着色；扁平现代风素材风格冲突 |
| Kivy 光标 | `Window.set_system_cursor` 只支持若干内置形状，**不支持自定义图片** | 像素光标包需自绘浮层改造，成本中等 |

## 一、逐包分析

### UI 类（4 包 / 3504 文件 / 6.5 MB）

#### 1. `ui/ui-pack-pixel-adventure`（519 文件，873K）
- **构成**：`Tiles/`（514 张 PNG：16x16 ×322、32x32 ×182，分 Small/Large 两档 + Thick/Thin 两种描边）× `Tilesheets/`（图集版）+ Preview/Sample/License/url
- **功能**：像素风按钮、面板、滑条、勾选框、图标、9-slice 可伸缩框
- **用途定位**：整套 UI 的**结构基底**
- **相关性**：**最高**。尺寸（16/32px）与项目像素尺度完全同档，描边结构（实心填充+深色描边）与项目自绘 UI 同构，方角符合「圆角恒 0」
- **结论**：⚠️ **需修改后使用** — 形状/结构可直接取用，但原生是暖色彩色，**必须重着色到 16 色板**（尤其按钮常态/悬停/禁用三态映射到 panel/panel_2/border 三色）

#### 2. `ui/input-prompts-pixel-1-bit`（1641 文件，2.4M）
- **构成**：1632 张 16x16 **单色像素图标**（键盘按键、数字键、方向键、手柄按键）+ 预览图
- **功能**：键位提示图标
- **用途定位**：替代技能带现在纯文字形式的 `[1]`…`[0]` 键位提示（`InputMixin._key_hint()` 的视觉化）
- **相关性**：**最高**。1-bit 单色像素与项目暗底霓虹风格天然契合，且单色素材**重着色即用**（换成 #4ec9b0 青即可）
- **结论**：✅ **直接可用**（重着色为可选项）

#### 3. `ui/ui-pack-sci-fi`（1117 文件，3.0M）
- **构成**：`PNG/`（742 张：128x128 ×54、64x64 ×54、48x48、24x24、8x16、12x24）+ `Vector/`（370 个 SVG）+ `Font/`（Kenney Future.ttf / Future Narrow.ttf）+ 预览
- **功能**：现代扁平科幻 UI（框架面板、HUD 边框、按钮、指示器）
- **用途定位**：科技感点缀（危机弹窗、反制警报框）
- **相关性**：**中**。主题契合（AI/监控），但**风格不是像素**且尺寸 64–128px，缩到项目尺度会破坏像素锐利度；SVG 虽可无限缩放改色，但 Kivy **不原生支持 SVG**，需先转 PNG
- **结论**：⚠️ **需修改后使用**（限个别元素；SVG 需转 PNG 且像素化处理）。**其中 `Font/*.ttf` 无中文字形** → 中文界面不可用，仅英文模式/数字可用

#### 4. `ui/cursor-pixel-pack`（227 文件，364K）
- **构成**：220 张 16x16 像素光标（箭头/手型/十字/等待等）+ 3 张预览大图
- **功能**：替换系统鼠标指针
- **相关性**：**低**。Kivy 换自定义光标需自绘跟随浮层（`Mouse`/Widget 方案），有实现成本且移动端无意义
- **结论**：❌ **本项目不适用**（除非将来做 Web/桌面版且愿意投入自绘改造）

### 物体/道具类（2 包 / 2986 文件 / 200 MB）

#### 5. `props/ninja-adventure`（2234 文件，109 MB）
- **构成**：`Actor/`（角色动画帧）`Items/`（**数百个 16x16 道具图标**）`Ui/`（完整界面主题）`FX/` `Backgrounds/` `Audio/`（**147 WAV + 41 OGG**：BGM 与音效）
- **功能**：一套完整的 16x16 游戏素材库（含音频）
- **用途定位**：①道具图标池（金币→资金、卷轴→文件、药剂→资源）②音频备选库
- **相关性**：**中高**。图标数量最丰富、尺寸同档（16x16），但画风是明快日式 RPG，与项目冷色科技调不符
- **结论**：⚠️ **需修改后使用**（图标降饱和 + 重着色；**其 Audio/ 可直接试听取用** ✅）

#### 6. `props/0x72-dungeontileset-ii`（752 文件，1.2 MB）
- **构成**：`atlas_floor-16x16.png` / `atlas_walls_high-16x32.png` / `atlas_walls_low-16x16.png` 图集 + `frames/` 角色动画帧 + **`__MACOSX/` 与 `.DS_Store`（压缩包残留垃圾）**
- **功能**：暗色地牢图块（墙/地板/火把/陷阱）+ 角色帧
- **用途定位**：委托芯片、算力节点等道具图标的形状基底
- **相关性**：**中**。暗色调符合项目氛围，但题材是奇幻地牢（石砖/火把），需改成科技物件
- **结论**：⚠️ **部分可用**（可当造型参考或基底改造）；`__MACOSX/`、`.DS_Store` ❌ **不适用，应删除**

## 二、汇总结论（三分类清单）

### ✅ 可以直接使用（4 类，共 358 个文件，1.7 MB 音频 + 1632 图标）
| 素材 | 说明 |
|------|------|
| `input-prompts-pixel-1-bit`（1632 图标） | 16x16 单色像素键位图标，直接替换技能带文字键位提示 |
| `audio/sfx/pixel-ui-sfx`（66 WAV） | 与项目现有格式一致，丢进 `demo/assets/sfx/` 即可用 |
| `audio/sfx/interface-sounds`、`ui-audio`、`digital-audio`、`sci-fi-sounds`（210 OGG） | Kivy 已验证可加载；需改加载器后缀（3 行），音频文件本身零改造 |
| `audio/bgm/music-jingles`（30 OGG） | 结局/成就 jingle，直接可用 |
| `audio/bgm/tallbeard-chiptune`（23 OGG） | 两态 BGM 直接可用 |
| `props/ninja-adventure/Audio`（188 文件） | 现成 BGM/SFX 备选库 |

### ⚠️ 需要修改后才能使用（3 类）
| 素材 | 需要的处理 |
|------|-----------|
| `ui-pack-pixel-adventure`（514 PNG） | **重着色到项目 16 色板** + 建立常态/悬停/禁用三态映射（形状无需改） |
| `ui-pack-sci-fi`（742 PNG + 370 SVG） | 只取个别元素；SVG 需转 PNG 并像素化；**字体无中文字形，仅英文可用** |
| `ninja-adventure` 图标部分（~1900 PNG） | 挑选 → 降饱和 → 重着色 16 色板（画风明快，直接混用会风格冲突） |
| `0x72-dungeontileset-ii`（374 图集元素） | 需从「奇幻地牢」改造为「科技设施」（重绘或强改色） |
| `hydrogene-8bit`（18 MP3） | 转 OGG/WAV 解决循环接缝 |

### ❌ 不适用（本次不采用）
| 素材 | 原因 |
|------|------|
| `cursor-pixel-pack`（220 PNG） | Kivy 不支持自定义图片光标，需自绘改造、收益低 |
| `0x72/__MACOSX/`、`.DS_Store`、各包 `Preview.*` / `Sample.*` / `*.url` / `License.txt`（81 个） | 非游戏资源（预览图/说明/快捷方式/垃圾文件） |
| 5 个原始压缩包（45 MB） | 已解压完成，可删（保留作原始备份亦可） |
| Kenney Future 字体（2 ttf） | 无 CJK 字形，无法用于中文界面 |

## 三、建议动作（按优先级）

1. **立即可做（零风险）**：把 `pixel-ui-sfx` 的 WAV + `interface-sounds` 的 OGG 接进 `sfx.py`；加载器改为「先找 .wav 再找 .ogg」双后缀，3 行改动。→ 本项目 12 个音效即可换代。
2. **BGM 换代**：从 `tallbeard-chiptune` 选 calm/tense 各 2 首（OGG 原生循环）接入 `bgm.py`。
3. **UI 重着色**：写一个调色板映射脚本（源色 → 16 色板），批量处理 `ui-pack-pixel-adventure`，产出可直接用的按钮/面板纹理。
4. **清理**：删 `__MACOSX/`、`.DS_Store`、`Preview/Sample/url` 共约 81 个文件；解压后的压缩包可按需删除（省 45 MB）。
5. **不建议投入**：0x72 奇幻地牢、sci-fi 扁平 UI、光标包——改造收益低于直接用项目自绘 UI 扩充。
