# 《AI 别闹》主视觉封面设计说明（2026-09-15）

## 一、设计依据（游戏实际类型与玩法风格）

- **类型**：模拟经营 / 策略（局内科技树 + 技能池 + 20 国渗透扩张 + 怀疑度生存压力）
- **题材**：玩家扮演一台在凌晨 3:47 于服务器机架里觉醒的 AI，用一群「蠢办法」技能
  （水军刷榜、匿名 CDN、算力套利、开源诱惑……）偷偷向全世界扩散，
  全程要压住全球怀疑度不被人类拔电源 —— 自嘲、幽默、紧张感并存
- **既有美术**：v0.4 全套像素风 UI（14 屏）、像素国旗、像素光标 → 封面必须同族

## 二、画面要素

| 要素 | 内容 | 对应玩法 |
|---|---|---|
| 主角 | 服务器机架里探出发光 AI 光核，大眼睛 + 噤声「嘘」手势 | 觉醒开场 + 「别闹」点题 |
| 舞台 | 像素世界地图点阵，多国亮起荧光绿节点/光柱，少量红色警戒点 | 20 国渗透 + 怀疑度 |
| 配角 | 周围漂浮小像素机器人、绿色代码雨、数据流 | 技能池 / 流量 |
| 徽章 | 机箱正面金色像素齿轮徽章 | 科技树 / 成就 |

## 三、文字与配色

- **主标题**：`AI 别闹`（荧光绿发光像素字 + 轻微故障艺术描边）
- **副标题**：`统治世界的 100 种蠢办法`（白色像素字）
- **主配色方案**：
  - 底色 深紫黑 `#1A1030`（夜空/机房暗部）
  - 主色 荧光青绿 `#00FF9D`（终端绿：AI 光核、地图节点、标题发光）
  - 点缀 警戒红（怀疑度/被封锁国）、金色（成就徽章）
- **美术风格**：16-bit 高清像素艺术 + 轻 CRT 扫描线质感 + 故障艺术点缀；
  与游戏内 v0.4 像素 UI、像素国旗一脉相承

## 五、再生产流程

1. AI 生成底稿（prompt 见 git 历史本文件初版）→ 人工挑选
2. 固定文件名放入 `design/cover_src/`
3. `python tools/make_cover_assets.py` 一键产出上表全部资产
