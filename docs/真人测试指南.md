# 《AI 别闹》真人测试指南（M1 里程碑）

> 目标：**3 位以上真实玩家各跑一局**，拿到能指导下一步开发的反馈。
> 你不需要懂代码 —— 按下面 3 步走完一局即可，最后花 2 分钟填问卷。

---

## 一、怎么跑起来（约 2 分钟）

1. 解压 `AI别闹_项目方案_v2.zip`（解压到**不含中文和空格的路径更稳**，
   例如 `D:\games\aibienao\`）。
2. 进入 `AI别闹_项目方案_v2/demo/` 目录。
3. **双击 `run_demo.bat`**。

> 首次运行会自动检查依赖。若提示缺少 Python / Kivy，
> 见同目录 `README.md` 的「环境准备」一节，或直接把报错截图发我。

启动后会看到主菜单 → 点「开始新游戏」→ 新手引导会带你走一遍核心循环。

---

## 二、一局大概多久

- 一个周期约 **30 秒**（可暂停）。完整一局平均 **47 个周期**，
  也就是 **20～30 分钟**。
- 想快一点：按 `+` 加速、用「放置技能」快速投放。
- 玩到出现「结局」画面就算一局完成。**中途失败也是有效反馈**，
  请照样填写问卷。

### 快捷键

| 键 | 作用 |
|---|---|
| `空格` / 点顶部 | 暂停 / 继续 |
| `Tab` | 切换大洲筛选 |
| `+` / `-` | 地图缩放 |
| `F1` | 帮助页（含「节奏参考」） |
| `F11` | 全屏 |
| `Esc` | 菜单 / 返回 |

## 三、请重点留意这几件事

我们最想知道的**不是"好不好玩"，而是下面这些具体体验**：

1. **前 3 分钟看懂了吗？** 你知道自己在干什么吗？（"我是一款 AI，
   要让自己被更多国家下载，同时别被监管盯上"）
2. **地图看得懂吗？** 哪些国家拿下了、哪些被封锁了，能不能一眼分清？
3. **按下技能之后，你知道发生了什么吗？** 有没有"点了没反应"的感觉？
4. **数字在动吗？** 下载量 / 算力 / 怀疑度上涨时，你注意到了吗？
5. **节奏**：是太快、太慢，还是刚好？大概第几个周期你觉得"进入状态了"？
6. **卡住的地方**：有没有哪个界面/按钮你找不到、或者看不懂？
7. **最想吐槽的一点**是什么？（这一条最有价值，请务必写）
8. **会不会想再玩一局**？为什么？

## 五、遇到问题怎么办

| 现象 | 处理 |
|---|---|
| 双击没反应 | 用命令行跑 `run_demo.bat`，把黑色窗口的报错发我 |
| 报缺 kivy | `py -3.12 -m pip install kivy==2.3.1` |
| 画面卡 | 设置页打开「动效减弱」；或按 `F11` 全屏 |
| 存档想重来 | 删掉 `demo/saves/` 目录即可 |

**任何报错请直接截图** —— 崩溃信息对我们定位问题帮助极大。

## 六、给测试组织者的话

- 目标人数：**≥3 人**，最好覆盖「很少玩 / 一般 / 常玩策略游戏」三档。
- 优先记录**"卡住/看不懂"的具体时刻**，其次是主观喜好。
- 收集到的反馈请按上面的编号汇总，便于对照 `docs/游戏开发待办清单.md`
  排优先级。
- 已知设计边界（不算 bug，不必报）：
  - 全球渗透率**达不到 100%**，设计上限约 50%（这是刻意的）；
  - 单局 47 周期左右是当前平衡结果，"想更快"请通过加速/技能提速。
